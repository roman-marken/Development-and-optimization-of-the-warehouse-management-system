# Warehouse Management System

React + TypeScript складський кабінет із пошуком, фільтрами, оновленням залишків і видаленням товарів. API локально імітується через MSW.

## Запуск

```bash
npm install
npm run dev
```

## Перевірки й аналіз

```bash
npm test
npm run build
npm run analyze
```

Звіт аналізатора bundle створюється в `dist/bundle-analysis.html`. У dev-режимі список обгорнуто в React Profiler; його render measurements можна записувати в React DevTools Profiler.
